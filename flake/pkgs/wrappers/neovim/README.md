Hello this is my personal wrapped neovim config.

If you're considering switching to mnw / nix to configure neovim here are some
repositories that I took inspiration from.

- [viperML/dotfiles](https://github.com/viperML/dotfiles/tree/master/packages/neovim): Pretty based.
- [Gerg-L/nvim-flake](https://github.com/Gerg-L/nvim-flake): Author of mnw, massive use of lz.n for no reason.
- [sioodmy/dotflies](https://github.com/sioodmy/dotfiles/blob/main/user/wrapped/nvim): Not using mnw but looks based.
- [Rexcrazy804/Zaphkiel](https://github.com/Rexcrazy804/Zaphkiel/tree/master/users/dots/nvim)
- [nix-community/kickstart-nix.nvim](https://github.com/nix-community/kickstart-nix.nvim): I haven't checked it much but it seems fine.
- [nvim-lua/kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim/blob/master/init.lua): Not nix related but still useful, I haven't checked it much either.
